GRAPE Doppler spectrogram prototype

drag across the chart to zoom in time, double-click to zoom out
dB below the strongest carrier re-references every 10 s column to its own peak, so a path stays at its true level relative to the main one however the main one fades — that is the shading that makes the weak paths visible. dB over the noise floor is the absolute scale the static PNG uses. Columns: more windows fall in one screen column than there are pixels, so each column is either averaged (steady weak lines survive, noise averages away) or peak held (transients survive).
